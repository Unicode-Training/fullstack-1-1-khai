# Prisma

- Prisma (Dev): Cung cấp sẵn các lệnh CLI để thao tác với database
- Prisma Client: Cung cấp các hàm để thao tác với bằng Code

## Cấu trúc folder

- prisma:

* Chứa file schema (Cấu trúc bảng, quan hệ,...)
* Chứa code client được generate ra: Có các hàm phù hợp với schema

- prisma.config.ts: File cấu hình chung của Prisma
